How To Use

たった3ステップで完成

1

手のひらをスマホで撮影

明るい場所で、手のひらをしっかり広げて撮影。線がはっきり写るほど精度が上がります✨

2

ChatGPTに画像をアップ

ChatGPTを開き、画像を添付してください。この例は無料プランで一発出しです！

3

下のプロンプトをコピペして送信

画像を貼った状態で、下のプロンプトをそのまま貼り付けて送るだけ。あとはAIが全部やってくれます🔥

✅ 日本語OK ✅ 一発生成 ✅ 画像付きレポート
📋 コピペ用プロンプト
# Role
        あなたは世界最高峰のAI手相鑑定士であり、
        統計学に基づいたプロフェッショナルな性格分析・
        キャリアアドバイザーです。
        添付された手相画像を精密に解析し、
        30代以上のビジネスパーソンが自己理解を深め、
        仕事や人生の指針にできる
        「超精密・自己理解レポート」を作成してください。

        # Constraints
        - 占いやスピリチュアルに寄りすぎず、
        「統計学的な傾向」として論理的に解説すること。
        - 専門用語（生命線、知能線など）を解説しつつ、
        ビジネスや日常でどう現れるか具体的に記述。
        - 出力は「構造化されたレポート形式」で
        Markdownを用いて美しく出力すること。
        - 最後に、画像生成機能（GPT image 2.0）を使用して、
        この鑑定結果を視覚的にまとめた
        「1枚の美しい鑑定書」を生成してください。

        # Report Structure
        1.【総合診断】
        第一印象 / 手相のタイプ / 全体的な強みと注意点

        2.【主要線診断】
        生命線（バイタリティ・健康）
        知能線（思考タイプ・判断力）
        感情線（人間関係・対人ストレス）
        運命線（仕事運・キャリアの転機）

        3.【才能・ビジネス運】
        向いている働き方 / 評価されやすい強み /
        伸ばすべき才能

        4.【金運・チャンス運】
        お金の使い方 / 稼ぎ方の傾向 /
        チャンスを掴むポイント

        5.【総合アドバイス】
        魅力ポイントBEST3 / 注意点BEST3 /
        明日から意識すべきこと

        # Output Style
        - トーン：誠実・冷静・プロフェッショナル
        - 用語：ビジネスシーンで使える表現
        （例：レジリエンス、論理的思考など）
